# Aryaa Jaiswal — AI / ML Engineer Portfolio

A modern, high-performance portfolio website built for **Aryaa Jaiswal**, Computer Science Engineering (AI) student and aspiring AI/ML engineer. Showcasing agentic AI systems, multimodal emotion recognition, machine learning pipelines, and full-stack software engineering.

---

## 🚀 Featured Projects

- **DataNova** — AI Business Intelligence system translating natural-language queries into validated SQL with schema introspection and execution guardrails.
- **Ignitia** — Multi-agent startup operating system built with LangGraph that decomposes product vision into architectural and code artifacts.
- **RASA: Your Mental Health Companion** — Multimodal emotion recognition companion combining OpenCV/DeepFace micro-expression analysis and acoustic sentiment classification.
- **CHAPS: AI Post-Care Monitoring Agent** — Healthcare monitoring agent processing longitudinal vitals telemetry and generating automated recovery reports.
- **AstroStocks** — Experimental equity analytics terminal correlating planetary cycles and market data.

---

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion
- **Typography**: Outfit, Plus Jakarta Sans, JetBrains Mono
- **Visuals & 3D**: CSS 3D perspective carousels, responsive interactive modals, SVG icons via Lucide
- **Integrations**: Multi-provider email webhook (Web3Forms, Formspree, custom endpoints)

## 💻 Local Development

### Prerequisites
- Node.js (v18+)
- npm or bun

### Setup
```bash
# Clone the repository
git clone https://github.com/Aryaajaiswaal/aryaa-portfolio.git
cd aryaa-portfolio

# Install dependencies
npm install

# Copy environment template
cp .env.example .env

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

---

## 📦 Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
